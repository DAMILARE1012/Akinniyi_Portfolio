# Abraham Akinniyi — Portfolio

Personal portfolio for Abraham Akinniyi, MEP Project Engineer (Lagos, Nigeria).

**Stack:** React 19 · Redux Toolkit (RTK Query + slices) · Tailwind CSS v4 · Vite

## Getting started

```bash
npm install
npm run dev       # local dev server
npm run build     # production build -> dist/
npm run preview   # serve the production build locally
npm run images    # regenerate optimised photos, OG image, icons and CV copy
```

## Before deploying

Edit `.env`:

| Variable | Purpose |
| --- | --- |
| `VITE_SITE_URL` | The real public domain (no trailing slash). Drives the canonical URL, Open Graph/Twitter tags, JSON-LD, `robots.txt` and `sitemap.xml`. |
| `VITE_CONTACT_ENDPOINT` | Optional [Formspree](https://formspree.io) (or any JSON POST) endpoint. If empty, the contact form opens the visitor's email app with a pre-filled message instead. |

After deploying, submit `https://<your-domain>/sitemap.xml` in Google Search Console.

## Editing content

All text lives in [`public/data/portfolio.json`](public/data/portfolio.json) and is loaded through RTK Query. Update it (for example, to add an email address or a new role) and redeploy — no component changes needed. To move content to a CMS or backend later, change `baseUrl` in [`src/services/portfolioApi.js`](src/services/portfolioApi.js).

If the name, role or location changes, also update the static SEO tags and JSON-LD in [`index.html`](index.html). They are static so link previews on LinkedIn and WhatsApp (which don't run JavaScript) work.


## Theming

Colours are CSS variables in [`src/index.css`](src/index.css), redefined under `.dark`. Light (white) is the default; the visitor's choice is saved in `localStorage` and applied before first paint to avoid a flash of the wrong theme.
